# Projeto Orcei Fácil - Instruções

## Comunicação
- Toda a comunicação (perguntas, respostas e mensagens) deve ser feita obrigatoriamente em português.

## Fluxo de Trabalho
- **Testes Obrigatórios:** Antes de realizar qualquer commit, você DEVE obrigatoriamente rodar todos os testes (`npm test`) e garantir que todos passem.
- Sempre que finalizar uma tarefa, pergunte ao usuário se deve realizar o commit e o push para a branch `main`.
