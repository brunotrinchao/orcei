# 🎬 Roteiro de Vídeo — Orcei (8 clipes × 7s = 56s)

**Estilo:** Copywriting de resposta direta (gancho de dor → agitação → solução → prova → CTA com urgência).
**Público:** freelancer / autônomo que perde venda por orçamento lento ou amador.
**Padrão visual:** fundo limpo, legendas grandes, ritmo acelerado. Prints em 16:9 landscape, resolução máxima, dados REAIS (fictícios, porém plausíveis — nada de "Lorem").

> Fórmula usada: AIDA (Atenção → Interesse → Desejo → Ação) + urgência.
> Para cada clipe: cena, narração, legenda, **info de mídia em PT** (imagem ou vídeo) e **prompt detalhado em EN** abaixo.

## CLIPE 1 — GANCHO (0–7s)

**Objetivo:** fisgar a dor em 2 segundos.

- **Cena:** profissional digitando rápido numa mesa bagunçada; chat pulsando com "digitando..." sem resposta.
- **Narração:** "Seu cliente pediu o orçamento ontem. Até hoje você só mandou 'tá quase pronto'."
- **Legenda:** `ORÇAMENTO ATRASADO = VENDA PERDIDA`

## ✅ Checklist antes de gravar os prints

1. 16:9 landscape, 1920×1080+ sem barras de rolagem.
2. Dados fictícios plausíveis (nomes, valores, clientes — nada de "Lorem").
3. Modo claro salvo se a marca for dark.
4. Cursor visível + botões com realce (gravar com Highlighter/Cursor).
5. Sem dados reais/log — desenho limpo.
6. ~1s de pausa antes da ação (ajuda o nanobanana a animar imagem estática).

## 🎯 Prompt padrão p/ cada print (Gemini/nanobanana)

> "Anime esta imagem de interface de aplicativo web: caméra slow zoom na área central [especificar], destaque sutil no botão [qual], parallax leve, sem alterar cores da identidade (azul/verde), fundo limpo. Duração 7 segundos, fechar no elemento principal."
